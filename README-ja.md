# Prolog Syntax Highlighter (SWI)

SWI-Prolog向けのVS Code拡張機能です。Prologソースコードのシンタックスハイライトを提供します。

![Example of View](images/image1.png)

## 概要

この拡張機能は、VS CodeでPrologファイル（`.pl`, `.pro`, `.prolog`）を編集する際に、シンタックスハイライトと基本的なエディタサポートを提供します。

## 主な機能

### シンタックスハイライト
- **コメント**: 行コメント（`%`）およびブロックコメント（`/* */`）
- **文字列**: シングルクォート（`'...'`）およびダブルクォート（`"..."`）文字列
- **準引用符**: SWI-Prologの準引用符記法（`{|...|}`）
- **数値**: 
  - 整数
  - 浮動小数点数
  - 16進数（`0x...`）
  - 2進数（`0b...`）
  - 8進数（`0o...`）
  - 文字コード（`0'x`）
- **変数**: 
  - 匿名変数（`_`）
  - 名前付き変数（`_Var`, `Var`）
- **ディレクティブ**: `:- module`, `:- use_module`, `:- dynamic` など
- **DCG記法**: `-->` 演算子
- **演算子**: `=`, `is`, `=:=`, `==`, `:-`, `?-` など
- **組み込み述語**: `true`, `false`, `write`, `findall`, `member`, `append` など

### エディタ機能
- **自動補完**: 括弧（`()`, `[]`, `{}`）とクォート（`'`, `"`）の自動閉じ
- **コメント設定**: 行コメントおよびブロックコメントのトグル対応
- **インデント**: タブサイズ2スペース（デフォルト）

### ファイル関連付け
- `.pl` ファイルを自動的にPrologとして認識（設定で変更可能）
- `.pro`, `.prolog` 拡張子もサポート
